# 想定ユーザーと課題

## 目的

業務用チャットアプリで解決する問題を明確にするため、想定する組織、ユーザー、利用場面を整理する。

ここで整理した内容をもとに、`docs/02-scope.md` でMVPに含める機能を定義する。

## 想定する組織と利用場面

小規模なチームや組織で、口頭、メール、個人チャットなどを使って業務連絡を行っている状態を想定する。

主な利用場面は、チーム内の全体連絡、業務上の相談、仕様確認、不具合報告など、複数人で継続的に確認する必要がある情報の共有である。

## 解決する問題

- 連絡手段が複数に分かれ、必要な情報の所在が分かりにくい
- 口頭や個別のやり取りが残らず、過去の経緯を確認しにくい
- 異なる話題が混在し、必要な情報を探しにくい
- 誰がいつ発言した内容なのか把握しにくい
- 担当者の変更やメンバーの参加時に情報を引き継ぎにくい
- 組織の情報を関係者だけで共有することが難しい

## 想定ユーザー

| ユーザー       | 立場                       | 目的                                               |
| -------------- | -------------------------- | -------------------------------------------------- |
| 管理者ユーザー | チームの情報共有を管理する | 情報共有の場を用意し、話題ごとに会話を整理する     |
| 一般ユーザー   | チームの情報共有に参加する | 業務連絡を投稿し、必要な情報や過去の経緯を確認する |

## 想定利用シナリオ

### チームの情報共有を開始する

管理者ユーザーがチーム用の情報共有環境を用意し、ほかのメンバーが参加できるようにする。

### 話題ごとに情報を共有する

管理者ユーザーが業務内容に応じて会話の場を分け、ユーザーが適切な場所で情報を共有する。

### 過去のやり取りを確認する

ユーザーが話題ごとのやり取りを確認し、途中から参加した場合でも過去の経緯を把握する。
