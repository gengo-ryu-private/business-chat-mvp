# 画面一覧

## このドキュメントの目的

このドキュメントでは、業務用チャットアプリMVPで作成する画面を整理する。

`docs/02-users.md` では、小規模組織における業務連絡の課題を整理した。  
`docs/03-scope.md` では、その課題に対してMVPで対応する範囲を定義した。  
`docs/04-requirements.md` では、MVPで実装する機能要件を整理した。

このドキュメントでは、それらの要件をユーザーが操作する画面としてどのように提供するかを明確にする。

## 画面設計の方針

このMVPでは、画面数を増やしすぎず、以下の基本操作ができることを重視する。

- ユーザー登録
- ログイン
- ログアウト
- 新規テナント作成
- 参加コードによる既存テナント参加
- 所属テナント情報の確認
- チャンネル一覧の確認
- チャンネル作成
- チャンネル内のメッセージ確認
- メッセージ投稿

画面設計では、小規模組織の情報共有課題に対して、以下を実現することを目的とする。

| 課題 | 画面上の対応 |
|---|---|
| 連絡内容が分散する | チャンネル詳細画面でメッセージを集約する |
| 話題ごとに情報を整理しづらい | チャンネル一覧画面でチャンネルを管理する |
| 過去のやり取りを確認しづらい | チャンネル詳細画面でメッセージ一覧を表示する |
| 誰がいつ発言したか分かりづらい | メッセージ一覧に投稿者名と投稿日時を表示する |
| 組織単位で情報を管理しづらい | テナント情報画面で所属テナントを確認する |
| 関係者以外への情報共有を避けたい | ログイン状態に応じて画面アクセスを制御する |

## 画面一覧

MVPでは、以下の画面を作成する。

| 画面ID | 画面名 | 概要 |
|---|---|---|
| SCREEN-001 | ユーザー登録画面 | 新規ユーザー登録、新規テナント作成、既存テナント参加を行う |
| SCREEN-002 | ログイン画面 | 登録済みユーザーがログインする |
| SCREEN-003 | チャンネル一覧画面 | 所属テナント内のチャンネル一覧を表示する |
| SCREEN-004 | チャンネル詳細画面 | チャンネル内のメッセージ一覧表示と投稿を行う |
| SCREEN-005 | テナント情報画面 | 所属テナント情報と自分の権限を表示する |

## SCREEN-001: ユーザー登録画面

### 目的

新規ユーザーがアカウントを作成し、アプリを利用開始できるようにする。

登録時には、以下のどちらかを選択できる。

- 新しいテナントを作成する
- 既存テナントに参加する

新しいテナントを作成する場合、ユーザーは管理者ユーザーとして登録される。  
既存テナントに参加する場合、ユーザーは一般ユーザーとして登録される。

### 対応する要件

- AUTH-001
- TENANT-001
- TENANT-002

### 表示項目

- 画面タイトル
- ユーザー名入力欄
- メールアドレス入力欄
- パスワード入力欄
- 登録方法の選択
  - 新しいテナントを作成する
  - 既存テナントに参加する
- テナント名入力欄
- 参加コード入力欄
- 登録ボタン
- ログイン画面へのリンク
- エラーメッセージ
- ローディング表示

### 入力項目

| 項目 | 必須 | 表示条件 |
|---|---|---|
| ユーザー名 | 必須 | 常に表示 |
| メールアドレス | 必須 | 常に表示 |
| パスワード | 必須 | 常に表示 |
| テナント名 | 必須 | 新しいテナントを作成する場合 |
| 参加コード | 必須 | 既存テナントに参加する場合 |

### 主な操作

- ユーザー情報を入力する
- 新規テナント作成または既存テナント参加を選択する
- 登録ボタンを押す
- 登録成功後、チャンネル一覧画面へ遷移する
- 登録済みの場合、ログイン画面へ移動する

### バリデーション

- ユーザー名は必須
- メールアドレスは必須
- メールアドレスはメール形式であること
- パスワードは必須
- 新規テナント作成時はテナント名が必須
- 既存テナント参加時は参加コードが必須

### エラー表示

以下の場合、エラーメッセージを表示する。

- 必須項目が未入力の場合
- メールアドレス形式が不正な場合
- ユーザー登録に失敗した場合
- 参加コードが不正な場合

### 遷移

| 操作 | 遷移先 |
|---|---|
| 登録成功 | チャンネル一覧画面 |
| ログイン画面へのリンク押下 | ログイン画面 |

### 入力項目

### 主な操作

- 未登録の場合、ユーザー登録画面へ移動する

### バリデーション

- メールアドレスは必須
- メールアドレスはメール形式であること
- パスワードは必須

### エラー表示

- 必須項目が未入力の場合

### 遷移

|---|---|
| ログイン成功 | チャンネル一覧画面 |

## SCREEN-003: チャンネル一覧画面

### 目的

ログインユーザーが、所属テナント内のチャンネルを確認できるようにする。

管理者ユーザーは、この画面からチャンネルを作成できる。

この画面により、話題ごとに情報共有の場所を分けられるようにする。

### 対応する要件

- CHANNEL-001
- CHANNEL-002
- PERMISSION-001
- PERMISSION-002

### 表示項目

- アプリ名
- 所属テナント名
- ログインユーザー名
- ユーザー種別
- チャンネル一覧
- チャンネル作成ボタン
- チャンネル作成フォーム
- テナント情報画面へのリンク
- ログアウトボタン
- ローディング表示
- エラーメッセージ

### チャンネル一覧に表示する項目

| 項目 | 説明 |
|---|---|
| チャンネル名 | チャンネルの名前 |
| チャンネル説明 | チャンネルの説明 |
| 作成日時 | チャンネルが作成された日時 |

### 主な操作

- チャンネル一覧を確認する
- チャンネルを選択してチャンネル詳細画面へ移動する
- 管理者ユーザーはチャンネルを作成する
- テナント情報画面へ移動する
- ログアウトする

### チャンネル作成フォーム

管理者ユーザーがチャンネル作成ボタンを押した場合、チャンネル作成フォームを表示する。

#### 入力項目

| 項目 | 必須 |
|---|---|
| チャンネル名 | 必須 |
| チャンネル説明 | 任意 |

#### バリデーション

- チャンネル名は必須
- チャンネル名は同一テナント内で重複しないこと

### 権限制御

| ユーザー種別 | チャンネル作成ボタン | チャンネル作成 |
|---|---|---|
| 管理者ユーザー | 表示する | 可能 |
| 一般ユーザー | 表示しない | 不可 |

一般ユーザーが直接チャンネル作成処理を呼び出した場合も、作成を拒否する。

### エラー表示

以下の場合、エラーメッセージを表示する。

- チャンネル一覧の取得に失敗した場合
- チャンネル名が未入力の場合
- チャンネル名が重複している場合
- チャンネル作成に失敗した場合
- 権限のない操作を行った場合

### 遷移

| 操作 | 遷移先 |
|---|---|
| チャンネル選択 | チャンネル詳細画面 |
| テナント情報リンク押下 | テナント情報画面 |
| ログアウト | ログイン画面 |

## SCREEN-004: チャンネル詳細画面

### 目的

ユーザーがチャンネル内のメッセージを確認し、新しいメッセージを投稿できるようにする。

この画面により、口頭・メール・個人チャットに分散していた業務連絡を、チャンネル単位で蓄積できるようにする。

### 対応する要件

- CHANNEL-003
- MESSAGE-001
- MESSAGE-002
- MESSAGE-003
- PERMISSION-002

### 表示項目

- アプリ名
- 所属テナント名
- ログインユーザー名
- チャンネル名
- チャンネル説明
- メッセージ一覧
- メッセージ入力欄
- 投稿ボタン
- チャンネル一覧画面への戻るリンク
- ログアウトボタン
- ローディング表示
- エラーメッセージ

### メッセージ一覧に表示する項目

| 項目 | 説明 |
|---|---|
| 投稿者名 | メッセージを投稿したユーザー名 |
| 投稿日時 | メッセージが投稿された日時 |
| メッセージ本文 | 投稿された内容 |

### 入力項目

| 項目 | 必須 |
|---|---|
| メッセージ本文 | 必須 |

### 主な操作

- チャンネル内のメッセージ一覧を確認する
- メッセージを入力する
- 投稿ボタンを押す
- 投稿成功後、メッセージ一覧に新しいメッセージを表示する
- 投稿成功後、入力欄を空にする
- チャンネル一覧画面へ戻る

### バリデーション

- メッセージ本文は必須
- 空白のみのメッセージは投稿できない

### 表示順

メッセージは投稿日時の昇順で表示する。

### エラー表示

以下の場合、エラーメッセージを表示する。

- チャンネル情報の取得に失敗した場合
- メッセージ一覧の取得に失敗した場合
- メッセージ本文が未入力の場合
- メッセージ本文が空白のみの場合
- メッセージ投稿に失敗した場合
- 所属テナント外のチャンネルにアクセスしようとした場合

### 遷移

| 操作 | 遷移先 |
|---|---|
| 戻るリンク押下 | チャンネル一覧画面 |
| ログアウト | ログイン画面 |

## SCREEN-005: テナント情報画面

### 目的

ログインユーザーが、自分の所属テナント情報とユーザー種別を確認できるようにする。

管理者ユーザーは、既存テナント参加用の参加コードを確認できる。

この画面により、ユーザーがどの組織に所属しているかを確認できるようにする。

### 対応する要件

- TENANT-003
- TENANT-004
- PERMISSION-002

### 表示項目

- アプリ名
- テナント名
- ログインユーザー名
- メールアドレス
- ユーザー種別
- 参加コード
- チャンネル一覧画面への戻るリンク
- ログアウトボタン
- ローディング表示
- エラーメッセージ

### 参加コードの表示制御

| ユーザー種別 | 参加コード |
|---|---|
| 管理者ユーザー | 表示する |
| 一般ユーザー | 表示しない |

### 主な操作

- 所属テナント情報を確認する
- 自分のユーザー種別を確認する
- 管理者ユーザーは参加コードを確認する
- チャンネル一覧画面へ戻る
- ログアウトする

### エラー表示

以下の場合、エラーメッセージを表示する。

- テナント情報の取得に失敗した場合
- ユーザー情報の取得に失敗した場合
- 所属テナント外の情報にアクセスしようとした場合

### 遷移

| 操作 | 遷移先 |
|---|---|
| 戻るリンク押下 | チャンネル一覧画面 |
| ログアウト | ログイン画面 |

## 共通レイアウト

認証後の画面では、共通して以下を表示する。

- アプリ名
- 所属テナント名
- ログインユーザー名
- ログアウトボタン

対象画面は以下とする。

- チャンネル一覧画面
- チャンネル詳細画面
- テナント情報画面

## 認証制御

未ログインユーザーが以下の画面にアクセスしようとした場合、ログイン画面へ遷移する。

- チャンネル一覧画面
- チャンネル詳細画面
- テナント情報画面

ログイン済みユーザーがログイン画面またはユーザー登録画面にアクセスした場合、チャンネル一覧画面へ遷移する。

## 権限制御

MVPでは、以下の画面制御を行う。

| 制御内容 | 対象画面 |
|---|---|
| 未ログインユーザーは認証後画面にアクセスできない | チャンネル一覧、チャンネル詳細、テナント情報 |
| 一般ユーザーにはチャンネル作成ボタンを表示しない | チャンネル一覧 |
| 一般ユーザーには参加コードを表示しない | テナント情報 |
| 所属テナント外のチャンネル詳細にはアクセスできない | チャンネル詳細 |
| 所属テナント外のテナント情報にはアクセスできない | テナント情報 |

## エラー表示

MVPでは、以下のエラーを画面上に表示する。

- 入力必須項目が未入力の場合
- メールアドレス形式が不正な場合
- ユーザー登録に失敗した場合
- ログインに失敗した場合
- 参加コードが不正な場合
- チャンネル一覧取得に失敗した場合
- チャンネル作成に失敗した場合
- メッセージ一覧取得に失敗した場合
- メッセージ投稿に失敗した場合
- テナント情報取得に失敗した場合
- 権限のない操作を行った場合

エラー発生時には、ユーザーが次に何をすべきか分かる文言を表示する。

## ローディング表示

以下の処理中は、ローディング表示を行う。

- ユーザー登録処理中
- ログイン処理中
- チャンネル一覧取得中
- チャンネル作成中
- メッセージ一覧取得中
- メッセージ投稿中
- テナント情報取得中

## URL設計

MVPでは、以下のURLを想定する。

| URL | 画面 |
|---|---|
| `/signup` | ユーザー登録画面 |
| `/login` | ログイン画面 |
| `/channels` | チャンネル一覧画面 |
| `/channels/[channelId]` | チャンネル詳細画面 |
| `/tenant` | テナント情報画面 |

## 主要な画面遷移

```text
/signup
  └─ 登録成功 → /channels

/login
  └─ ログイン成功 → /channels

/channels
  ├─ チャンネル選択 → /channels/[channelId]
  ├─ テナント情報 → /tenant
  └─ ログアウト → /login

/channels/[channelId]
  ├─ 戻る → /channels
  └─ ログアウト → /login

/tenant
  ├─ 戻る → /channels
  └─ ログアウト → /login
```

## MVPでは作成しない画面

初期MVPでは、以下の画面は作成しない。

- ユーザー管理画面
- 招待メール送信画面
- チャンネル編集画面
- チャンネル削除確認画面
- メッセージ検索画面
- メッセージ編集画面
- メッセージ削除確認画面
- 通知設定画面
- プロフィール編集画面
- 複数テナント切り替え画面
- 管理者向け詳細設定画面

## 完了条件

この画面設計は、以下を満たす状態で完了とする。

- ユーザー登録画面の役割が明確である
- ログイン画面の役割が明確である
- チャンネル一覧画面の役割が明確である
- チャンネル詳細画面の役割が明確である
- テナント情報画面の役割が明確である
- 各画面の表示項目、入力項目、主な操作が整理されている
- 各画面の遷移先が整理されている
- MVPで必要な認証制御と権限制御が整理されている
- MVPで作成しない画面が明確である
