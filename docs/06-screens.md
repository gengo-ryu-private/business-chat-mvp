# 画面設計

## 目的

`docs/03-requirements.md` の機能要件を、ユーザーが操作する画面としてどのように提供するかを定義する。

入力条件や権限制御の詳細は機能要件を正とし、このドキュメントでは表示項目、操作、遷移を扱う。

## 画面一覧

| 画面ID     | URL                     | 画面           | 関連要件                                                           |
| ---------- | ----------------------- | -------------- | ------------------------------------------------------------------ |
| SCREEN-001 | `/signup`               | ユーザー登録   | AUTH-001、TENANT-001、TENANT-002                                   |
| SCREEN-002 | `/login`                | ログイン       | AUTH-002                                                           |
| SCREEN-003 | `/channels`             | チャンネル一覧 | CHANNEL-001、CHANNEL-002、PERMISSION-001、PERMISSION-002           |
| SCREEN-004 | `/channels/[channelId]` | チャンネル詳細 | CHANNEL-003、MESSAGE-001、MESSAGE-002、MESSAGE-003、PERMISSION-002 |
| SCREEN-005 | `/tenant`               | テナント情報   | TENANT-003、PERMISSION-002                                         |

## SCREEN-001: ユーザー登録

新しいテナントを作成するか、既存テナントへ参加してユーザー登録する画面。

| 表示・入力項目 | 表示条件                 |
| -------------- | ------------------------ |
| ユーザー名     | 常に表示                 |
| メールアドレス | 常に表示                 |
| パスワード     | 常に表示                 |
| 登録方法       | 常に表示                 |
| テナント名     | 新規テナント作成時に表示 |
| 参加コード     | 既存テナント参加時に表示 |
| 登録ボタン     | 常に表示                 |

- 登録成功後は`/channels`へ遷移する
- 登録済みユーザーは`/login`へ移動できる
- 入力または登録処理に問題がある場合は画面内にエラーを表示する

## SCREEN-002: ログイン

登録済みユーザーがメールアドレスとパスワードでログインする画面。

- メールアドレス入力欄、パスワード入力欄、ログインボタンを表示する
- ログイン成功後は`/channels`へ遷移する
- 未登録ユーザーは`/signup`へ移動できる
- 入力またはログイン処理に問題がある場合は画面内にエラーを表示する

## SCREEN-003: チャンネル一覧

所属テナントのチャンネルを確認し、管理者ユーザーがチャンネルを作成する画面。

### 表示項目

- 所属テナント名、ログインユーザー名、ユーザー種別
- チャンネル名、説明、作成日時
- テナント情報画面へのリンク
- ログアウトボタン

管理者ユーザーにはチャンネル作成フォームを表示し、一般ユーザーには表示しない。

チャンネル作成フォームには、チャンネル名入力欄、説明入力欄、作成ボタンを表示する。

| 操作               | 結果                              |
| ------------------ | --------------------------------- |
| チャンネルを選択   | `/channels/[channelId]`へ遷移する |
| チャンネルを作成   | 作成後に一覧を更新する            |
| テナント情報を選択 | `/tenant`へ遷移する               |
| ログアウト         | `/login`へ遷移する                |

## SCREEN-004: チャンネル詳細

チャンネルのメッセージを確認し、新しいメッセージを投稿する画面。

### 表示項目

- チャンネル名と説明
- 投稿者名、投稿日時、本文を含むメッセージ一覧
- メッセージ入力欄と投稿ボタン
- チャンネル一覧へ戻るリンク
- ログアウトボタン

- メッセージは投稿日時の昇順で表示する
- 新しいメッセージは画面更新なしで一覧へ反映する
- 投稿成功後は入力欄を空にする
- 戻る操作では`/channels`、ログアウトでは`/login`へ遷移する

## SCREEN-005: テナント情報

所属テナントとログインユーザーの情報を確認する画面。

- テナント名、ユーザー名、メールアドレス、ユーザー種別を表示する
- 参加コードは管理者ユーザーだけに表示する
- 戻る操作では`/channels`、ログアウトでは`/login`へ遷移する

## 共通仕様

### 認証後レイアウト

認証後の画面には、アプリ名、所属テナント名、ログインユーザー名、ユーザー種別、主要画面へのナビゲーション、ログアウトボタンを共通して表示する。

### 認証制御

- 未ログインユーザーが認証後の画面へアクセスした場合は`/login`へ遷移する
- ログイン済みユーザーが`/login`または`/signup`へアクセスした場合は`/channels`へ遷移する

### エラーとローディング

- 入力、認証、権限、データ取得・作成のエラーを画面内に表示する
- 登録、ログイン、データ取得・作成の処理中はローディング状態を表示する
