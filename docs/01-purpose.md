# ポートフォリオ作成の目的

## 背景

このポートフォリオは、自社開発企業への転職活動において、自分がWebアプリケーション開発を一通り進められることを示すために作成する。

転職活動では、以下のような力を示す必要があると考えたため、このポートフォリオを作成しています。

- 業務課題を理解する力
- 必要な機能を整理する力
- MVPとしてスコープを絞る力
- フロントエンド・バックエンド・データ構造を一貫して設計する力
- 実装だけでなく、テストや品質も考慮する力
- 将来的な拡張を見据えて構成を考える力

## 作成方針

今回のポートフォリオでは、機能数を増やしすぎることよりも、MVPとして必要な範囲を明確にし、設計・実装・テストを丁寧に進めることを重視する。

そのため、初期リリースでは以下を優先する。

- 認証
- テナント管理
- チャンネル管理
- メッセージ投稿・表示
- 主要機能のテスト

一方で、以下のような機能は初期MVPの対象外とする。

- ファイル添付
- メンション
- リアクション
- スレッド返信
- 通知
- 既読管理
- 高度な権限管理

これらは、将来的な拡張候補として扱う。
