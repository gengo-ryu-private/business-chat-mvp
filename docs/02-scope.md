# MVPスコープ

## 目的

`docs/01-users.md` で整理した課題をもとに、業務用チャットアプリMVPに含める機能と含めない機能を定義する。

想定ユーザーの主要な課題を解決でき、設計、実装、テストまで完了できる最小限の範囲に絞る。

## 課題とMVPでの対応

| 課題                                         | MVPでの対応                                              |
| -------------------------------------------- | -------------------------------------------------------- |
| 連絡手段が分かれ、情報の所在が分かりにくい   | チャンネル内にメッセージを集約する                       |
| 過去の経緯を確認しにくい                     | チャンネルごとにメッセージを保存して一覧表示する         |
| 異なる話題が混在し、必要な情報を探しにくい   | 話題ごとにチャンネルを分ける                             |
| 誰がいつ発言したのか把握しにくい             | メッセージに投稿者名と投稿日時を表示する                 |
| メンバーの参加時や担当変更時に引き継ぎにくい | 既存組織への参加と過去のメッセージ確認を可能にする       |
| 組織の情報を関係者だけで共有することが難しい | 認証とテナント単位のデータ分離によってアクセスを制限する |

## MVPに含める機能

| 分類         | 機能                                                           |
| ------------ | -------------------------------------------------------------- |
| 認証         | ユーザー登録、ログイン、ログアウト、未認証時のアクセス制御     |
| テナント管理 | 新規テナント作成、参加コードによる参加、所属テナント情報の表示 |
| チャンネル   | 一覧・詳細表示、管理者ユーザーによる作成                       |
| メッセージ   | 投稿・一覧表示、リアルタイム反映、投稿者名・投稿日時の表示     |
| 権限制御     | テナント単位のデータ分離、ユーザー種別によるチャンネル作成制限 |
| テスト       | 関数、コンポーネント、E2E、Firestore Security Rulesのテスト    |

## MVPに含めない機能

| 分類                     | 機能                                                                                                           |
| ------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 高度なメッセージ機能     | ファイル・画像添付、メンション、リアクション、スレッド、ダイレクトメッセージ、通知、既読管理、検索、編集、削除 |
| チャンネル管理の拡張     | チャンネルの編集・削除、チャンネルごとの閲覧・投稿権限                                                         |
| ユーザー・組織管理の拡張 | 招待メール、ユーザー削除、管理者権限の変更、複数管理者、複数テナント所属                                       |
| その他                   | 外部サービス連携、監査ログ、管理者向け詳細設定                                                                 |

これらは主要課題の解決に必須ではなく、MVPの実装範囲を広げるため対象外とする。
