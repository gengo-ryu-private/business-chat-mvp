# 機能要件

## 目的

`docs/02-scope.md` で定義した機能について、ユーザーができることと満たすべき振る舞いを定義する。

データ構造は `docs/04-data-model.md`、処理手順は `docs/05-data-flow.md`、画面構成は `docs/06-screens.md` に整理する。

## 共通前提

- ユーザーは1つのテナントに所属する
- ユーザー種別は管理者ユーザー（`admin`）と一般ユーザー（`member`）の2種類とする
- 新規テナントを作成したユーザーは管理者ユーザーになる
- 参加コードで既存テナントに参加したユーザーは一般ユーザーになる

## 認証要件

### AUTH-001: ユーザー登録

ユーザーは、新しいテナントを作成するか、参加コードで既存テナントに参加してアカウントを作成できる。

| 項目           | 条件                                                   |
| -------------- | ------------------------------------------------------ |
| ユーザー名     | 必須、前後空白を除いて50文字以内                       |
| メールアドレス | 必須、メールアドレス形式                               |
| パスワード     | 必須                                                   |
| テナント名     | 新しいテナントを作成する場合に必須、50文字以内         |
| 参加コード     | 既存テナントに参加する場合に必須、10文字の英数字大文字 |

### AUTH-002: ログイン

登録済みユーザーは、メールアドレスとパスワードでログインできる。

- メールアドレスとパスワードを必須とする
- メールアドレスはメールアドレス形式とする

### AUTH-003: ログアウト

ログイン中のユーザーはログアウトできる。

### AUTH-004: 認証制御

- 未ログインユーザーは認証後の画面へアクセスできない
- ログイン済みユーザーはログイン画面またはユーザー登録画面を利用しない

## テナント要件

### TENANT-001: テナント作成

ユーザーは、登録時に新しいテナントを作成できる。

- 参加コードは、誤読しやすい`0`、`O`、`I`、`1`を除いた10文字の英数字大文字で、暗号学的に安全な乱数を使ってシステムが生成する
- 作成したユーザーを管理者ユーザーとしてテナントに所属させる

### TENANT-002: 既存テナントへの参加

ユーザーは、登録時に有効な参加コードを入力して既存テナントに参加できる。

- 参加したユーザーを一般ユーザーとしてテナントに所属させる
- 参加コードが無効な場合は参加できない

### TENANT-003: 所属テナント情報の表示

ログインユーザーは、所属テナントと自分の情報を確認できる。参加コードを確認できるのは管理者ユーザーだけとする。

## チャンネル要件

### CHANNEL-001: チャンネル作成

管理者ユーザーは、所属テナント内にチャンネルを作成できる。

| 項目             | 条件                               |
| ---------------- | ---------------------------------- |
| チャンネル名     | 必須、50文字以内、テナント内で一意 |
| チャンネルの説明 | 任意、200文字以内                  |

### CHANNEL-002: チャンネル一覧表示

ログインユーザーは、所属テナント内のチャンネル一覧を確認できる。

### CHANNEL-003: チャンネル詳細表示

ログインユーザーは、所属テナント内のチャンネルを選択し、詳細を確認できる。

## メッセージ要件

### MESSAGE-001: メッセージ投稿

ログインユーザーは、所属テナント内のチャンネルにメッセージを投稿できる。

- 本文は前後空白を除いて1文字以上1000文字以内とする

### MESSAGE-002: メッセージ一覧表示

ログインユーザーは、選択したチャンネルのメッセージを確認できる。

チャンネルを開いている間に新しいメッセージが投稿された場合は、画面更新なしで一覧へ反映する。

### MESSAGE-003: 投稿者と投稿日時の表示

ユーザーは、各メッセージの投稿者と投稿日時を確認できる。

## 権限制御要件

### PERMISSION-001: 一般ユーザーのチャンネル作成制限

一般ユーザーはチャンネルを作成できない。

### PERMISSION-002: テナント外データへのアクセス制限

ユーザーは、自分のユーザー情報と、所属テナントのテナント、チャンネル、メッセージだけを参照・操作できる。
